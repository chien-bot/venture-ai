# CareAI 本周开发进度

## 本周目标

完成一个可演示的“健康数据 → 风险规则 → AI 健康报告 → 历史趋势”的最小产品闭环。

## 已完成

| 模块 | 交付内容 | 状态 |
| --- | --- | --- |
| 数据输入 | 年龄、性别、身高、体重、血压、睡眠、运动与可选空腹血糖 | 完成 |
| 规则引擎 | BMI、睡眠、运动、血压、空腹血糖；输出 `normal / attention / high_attention` | 完成 |
| Health Report Agent | 只解释规则结果，生成建议与 7 天行动计划；安全校验不通过时自动重写一次 | 完成 |
| 模型接入 | 支持学校 MaaS 与 OpenRouter；密钥仅从环境变量读取 | 完成 |
| 历史与趋势 | SQLite 保存分析报告；提供历史、详情和趋势接口 | 完成 |
| 前端 Demo | 健康录入、报告、行动计划、历史趋势、前后对比与异常重试 | 完成 |
| 可解释性 | 版本化规则配置、规则信息接口和公共健康参考链接 | 完成 |

## 当前技术闭环

```text
React + Tailwind
        ↓
FastAPI API
        ↓
确定性风险规则 ─────→ 风险等级与来源
        ↓                         ↓
Health Report Agent ← 仅接收规则已确定的风险项
        ↓
结构化 JSON 健康报告
        ↓
SQLite 历史记录与趋势对比
```

## 已验证内容

- 后端自动化测试：`11 passed`。
- 完整分析接口可生成固定结构报告并写入 SQLite。
- 血糖未输入时不生成血糖风险标签；输入时标签带 `user_input.blood_glucose` 来源。
- 模型输出必须通过 JSON、风险类别和非诊断边界校验；未通过时不保存报告。
- 前端生产构建通过。
