# CareAI Stage 2 开发进度

更新时间：2026-09-10

## 已实现

| Stage 2 项目 | 状态 | 当前实现 |
| --- | --- | --- |
| P0-1 个人档案与资料隔离 | 已实现 | SQLite `users`、`user_id` 隔离、档案编辑／切换、删除单条健康记录 |
| P0-2 健康 Memory 时间轴 | 已实现 | 每条报告保存记录日期、来源、个人目标；历史页以时间轴展示 |

| P0-4 长期计划与复盘 | 已实现 | 行动任务保存至后端、完成状态和未完成原因可保存、历史页显示最新周复盘 |
| P1-2 医生健康摘要 | 已实现 API | `GET /api/v1/health/doctor-summary` 输出档案、趋势提示、记录数和计划复盘，供后续页面／PDF 使用 |
| P1-1 报告导入与结构化 | 部分实现 | 支持粘贴电子报告文字或读取 TXT，提取草稿后由用户逐项确认；未接入 PDF／图片 OCR、设备或医院系统 |
| P2 每周 AI 复盘与计划调整 | 已实现 | 根据个人目标、完成率和既有趋势提示生成 7 天草稿；用户确认后保存为下一轮复盘来源，且模型输出受非诊断约束 |

## 本次验证

- 后端自动化测试：17 项通过，其中新增用户隔离、行动计划持久化、睡眠趋势识别、报告文字提取和 AI 周计划安全测试。
- 前端生产构建：通过。

## 安全边界

- 本地档案切换用于课堂演示的数据隔离，不是生产环境的身份认证或授权体系。
- 趋势输出为非诊断性健康提醒；不会输出疾病诊断、药物剂量或处方。
- 未接入医院、诊所、Apple Health、Google Fit 或真实医疗设备。
