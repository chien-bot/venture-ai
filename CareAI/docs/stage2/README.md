# CareAI 第二阶段材料索引

第二阶段的目标是将第一阶段已经完成的“单次健康分析与历史记录”MVP，升级为具有差异化的“终生健康 Memory 与主动健康管理”原型。

| 文件 | 用途 |
| --- | --- |
| `stage2-development-plan.md` | 开发范围、优先级、验收标准、边界与演示主线 |

## 第二阶段一句话目标

> CareAI 不只解释一次健康资料；它持续记住个人健康变化、发现值得关注的趋势，并帮助用户执行和复盘个人化健康计划。

## 开发原则

- 先完成可演示、可测试的核心闭环，再扩展设备、医院或医生系统对接。
- 所有健康提示均为非诊断性健康教育与风险提醒，不输出疾病诊断、处方或剂量建议。
- 真实医疗数据、真实医生协作和第三方设备数据必须在取得授权、落实数据隔离与安全措施后才能使用。
