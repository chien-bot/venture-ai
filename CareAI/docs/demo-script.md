# CareAI MVP 演示脚本（约 5 分钟）

## 演示前检查

1. 后端：`cd backend` 后执行 `uvicorn app.main:app --reload`。
2. 配置模型环境变量。校外演示可使用 `LLM_PROVIDER=openrouter` 和 `OPENROUTER_API_KEY`；密钥不展示在屏幕或 PPT 中。
3. 前端：`cd frontend` 后执行 `npm run dev`，打开 `http://127.0.0.1:5173`。
4. 先打开 `http://127.0.0.1:8000/docs`，备用于展示接口和规则说明。

## 讲解主线

“CareAI 不是医疗问答机器人。它将风险判断交给可追溯的本地规则，把大模型限定为解释风险、给出生活方式建议和生成行动计划，并在后续记录中追踪变化。”

## 操作步骤

1. 首页：指出三个关键设计：**规则优先、AI Agent、非诊断边界**。
2. 健康分析页：点击“重点关注案例”。说明输入含有身高、体重、血压、睡眠、运动和可选的空腹血糖。
3. 提交：说明后端先调用规则引擎，再把已确定的风险项传给 Health Report Agent；模型没有资格增删风险或判断疾病。
4. 报告页：展示风险等级、风险标签中的“来源：user_input”、健康建议与 7 天行动计划。勾选任意一天，展示执行进度。
5. 再次分析：回到健康分析页，点击“作息待改善案例”或手动修改数据后提交。
6. 第二份报告：展示“本次与上次报告对比”，说明 BMI、睡眠、运动与规则风险等级均为数据变化描述，**不是医疗结论**。
7. 历史记录：展示 SQLite 保存的报告和趋势图；点击任意历史报告可回看原始输入、规则结果和 AI 报告。
8. 接口说明：在 `/docs` 打开 `GET /api/v1/health/rule-info`，展示规则版本、阈值、适用范围和专业复核提示。

## 备用说明

- 若模型服务不可用：展示页面的“重新尝试”提示，并说明系统不会保存未通过 AI 安全校验的报告；本地规则接口仍可独立演示。
- 若无历史数据：首次提交会建立趋势基线；第二次提交即可展示对比。
- 若被问及医疗安全：报告仅使用 `normal / attention / high_attention`，不输出疾病名称、确诊结论、处方或药物剂量。
