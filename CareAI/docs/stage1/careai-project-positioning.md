# CareAI 项目定位与选题矩阵 v0.1

## 一句话定位

CareAI 是一个面向成年人的 AI 辅助健康管理原型：将用户主动输入的基础健康数据转化为**可追溯的非诊断性风险提示、生活方式建议和 7 天行动计划**，帮助用户建立持续记录与自我管理习惯。

## 选题方向

挑战杯课程方向：**社会治理和公共服务**（健康教育与公共健康促进场景）。

### 最终选择：CareAI

选择理由：CareAI 已有可运行的前后端 MVP，能直接展示“健康数据 → 本地规则 → AI 解释 → 行动计划 → 历史趋势”的完整闭环；其健康教育、合理膳食、身体活动与自我管理场景能够找到权威公开资料支持。

放弃其他候选项的原因：候选 B 缺少与现有原型同等完整的差异化机制；候选 C 需要图像识别、饮食数据库和更复杂的准确性验证，超出当前课程时间与专业复核条件。

## 当前 MVP 的可核查功能事实（F）

以下内容来自当前 CareAI 源码与本地验证，不是市场或用户结论：

- 仅接收 18 岁及以上用户的基本健康数据；支持身高、体重、睡眠、每周运动天数，以及可选血压和空腹血糖。
- 本地规则引擎计算 BMI、睡眠、运动、血压和空腹血糖的 `normal`、`attention`、`high_attention` 提示；模型不允许新增风险类别或作出疾病诊断。
- Health Report Agent 仅负责解释已确定的风险、给出生活方式建议和 7 天行动计划。
- 系统将成功报告保存到本地 SQLite，并提供历史记录与趋势查看。
- 后端测试 11/11 通过；前端生产构建通过。测试时间：2026-09-05。

源码定位：`backend/app/schemas.py`、`backend/app/services/risk_rules.py`、`backend/app/services/health_report_agent.py`、`frontend/src/components/HealthForm.tsx`。

## 不做什么

- 不诊断疾病，不开具处方，不给出药物剂量；单次指标异常只作为复测、关注或线下咨询提示。
- 不面向未成年人；不处理急救、危急症状或医疗决策。
- 不把演示样例、Agent 输出或课堂模拟写成真实用户反馈或临床证据。
- 不在未完成授权、数据安全与专业复核前开展真实个人健康数据试用。
