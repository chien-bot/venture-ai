## 部署与复现

- 启动说明：根目录 `README.md`
- 后端依赖：`backend/requirements.txt`
- 前端依赖：`frontend/package-lock.json`
- 环境模板：`backend/.env.example` 或仓库对应环境示例；密钥只放本地环境变量
- 后端测试：`backend/.venv/bin/python -m unittest discover -s backend/tests -v`
- 前端检查：在 `frontend/` 执行 `npx tsc --noEmit` 和 `npm run build`
- 本地入口：前端 `http://localhost:3000`；后端健康检查 `http://localhost:8000/health`
