## 纳入项与验收条件

| 编号 | 问题与影响 | V2 处理 | 验收条件 |
| --- | --- | --- | --- |
| V2-01 | 未固定 LangChain 兼容版本时，图流程会在节点运行前失败 | 固定 `langchain==0.3.13`，与现有 LangGraph/Core 版本配套 | 新环境安装依赖后，tutor/coach/grader 均完成离线贯通测试 |
| V2-02 | `bcrypt` 和 `python-docx` 未在依赖清单中，导致认证初始化或文档导出无法复现 | 补入 `requirements.txt` | 按 README 安装可初始化数据库；文档导出依赖可定位 |
| V2-03 | 运行记录无法直接关联一次运行、版本和流程 | 每次非流式运行生成 `run_id`，日志加入版本、流程、模型、mock 状态与生命周期事件 | 测试验证三个流程和失败降级均能回溯到原始运行日志 |
| V2-04 | 前端生产构建依赖在线 Google 字体，受网络限制时无法构建 | 移除构建期字体下载，使用既有系统字体栈 | `npm run build` 在当前受限环境通过 |
| V2-05 | 缺少新环境启动与配置说明 | 新增根目录 README 与 `.env.example` | 非开发者可按文档找到配置、安装、启动和三个流程入口 |
