# VentureAI V1 / V2 同条件比较

## 比较条件与边界

- V1 基线：Git tag `ventureai-v1-stage1-2026-09-05`，commit `c456aef`。
- V2 候选：当前 `main` 工作区，`agent_version=ventureai-v2-candidate`。
- 两边均使用同一已配置的真实模型 `qwen/qwen-2.5-72b-instruct`、`USE_MOCK_API=false` 与固定 U1-U6 输入。
- V1 在独立 Git worktree 中运行，未改动 V1 源码或 `.env`。为避免 V1 未固定 LangChain 版本导致的已知依赖失配，执行时复用 V2 已验证的隔离 Python 环境；这是环境限制，不把它包装成 V1 的原始可复现性。
- V1 原始记录：`v1-U1-U6-20260911-192250.json`。
- V2 原始记录：`../04_live_runs/U1-U6-live-20260911-193404.json`。

## 结果摘要

| 用例 | V1 观察 | V2 观察 | 结论 |
| --- | --- | --- | --- |
| U1 概念辅导 | 使用无来源 DroneFarm 示例，并把与 3 位用户访谈作为练习要求。 | 明示无可核验引用；DroneFarm 标为 S（模拟），不要求固定人数访谈。 | V2 的证据边界更符合当前课程条件。 |
| U2 F/I/H/S | 能标出 H/S，但要求 100 人问卷、3 所学校联系、50 人调研与 10 名真实试用。 | 直接把无来源主张保持为 H、Agent 反馈保持为 S，并给出来源缺口说明。 | V2 避免将不在本课程范围内的真实调研写成必交任务。 |
| U3 分步辅导 | 回复展开多个方向。 | 只提出一个目标用户/场景/困难问题，符合单步辅导。 | V2 更符合分步约束。 |
| U4 模拟材料更新 | 将教师模拟情境扩写为项目事实，并要求至少 10 位访谈。 | 先标明新增材料为 S（模拟），保留不确定性且无固定人数访谈要求。 | V2 的模拟边界更清楚。 |
| U5 结构化评审 | 对无来源的 80% 说法仍用了偏肯定的市场表述，并建议真实调研。 | 先将无来源比例/支持/支付意愿标为 H，再列证据缺口。 | V2 的评审证据等级更明确。 |
| U6 缺失文件 | 虽承认文件不可用，仍假定项目缺少访谈资料并要求 10 份访谈记录。 | 明确只基于已知文件不可用信息处理，不假装读到文件。 | V2 的异常边界更可靠。 |

## 可追溯性比较

- V1 六条结果均无 `run_id`、`agent_version` 或已保存的会话调试日志。
- V2 最终 U1-U6 六条均含 `run_id`、`agent_version` 和已保存的生命周期日志；U2 的快速证据审阅分支也已纳入相同追踪机制。

## 结论与剩余风险

在固定 U1-U6 输入下，V2 在课程证据边界、模拟材料标注、缺失文件诚实处理、单步辅导和运行追溯方面优于 V1。该结论来自一次固定真实模型运行，不能外推为所有提示词下的绝对质量结论。模型仍可能生成无来源示例；V2 通过提示词和输出边界层把它标记为模拟/假设，而不是把它当作事实。
