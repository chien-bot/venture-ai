## 证据边界

`backend/tests/` 中的测试使用 mock 模式，证明的是路由、可运行性、日志和
异常处理，不能作为“真实模型输出质量提升”的唯一证据。真实模型运行必须将
`USE_MOCK_API=false`，并保存全部原始输入、输出、失败、重试和人工处理记录。
